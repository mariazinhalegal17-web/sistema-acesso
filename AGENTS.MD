# INSTRUÇÕES PARA AGENTES DE IA (AGENTS.MD)

## Diretrizes Principais
- **Design UI/UX**: Sempre priorizar interface corporativa, limpa e minimalista.
- **Estrutura de Código**: Manter organização em módulos JavaScript (Vanilla JS).
- **Tratamento de Erros**: Sempre validar se o funcionário existe antes de gravar o ponto e tratar retornos sem dados com `.maybeSingle()`.
- **Logs e Backlogs**: Manter registro claro de alterações, ajustes e correções em cada atualização.
